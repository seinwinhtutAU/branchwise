How to install

Windows

  1. Run the downloaded BranchWise-…-setup.exe.
  2. If a blue "Windows protected your PC" box appears, click More info, then Run anyway.

Mac

  1. Open the downloaded .dmg and drag BranchWise into Applications. Replace the old one if asked.
  2. Open Terminal and run this once, otherwise the Mac says the app is "damaged":
    xattr -cr /Applications/BranchWise.app
  3. Open BranchWise.

Updating? On Mac, install each new version this way. The in-app "Restart and Update" does not work yet.
