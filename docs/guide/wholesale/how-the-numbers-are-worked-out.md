# Wholesale: how every number is worked out (index)

Every figure in the wholesale app, grouped by what it is about. Each page says how the figure is worked out, with the exact rules and
numbers, and **why** it is done that way. Ask about any figure and the assistant reads the page that covers it. The current value of a
setting (exchange rates, the profit used for the suggested selling price, the health weights) is never written in these pages; the
assistant reads the value in use today.
